# Yahaya Abubakar — Portfolio

Minimal Soft-UI portfolio. Next.js App Router + TypeScript, SSG, Tailwind CSS tokens, Framer Motion subtle motion.

## Edit text
All content lives in `src/content/profile.ts`. Edit names, roles, links, availability there — no component changes needed.

## Run
```bash
npm install
npm run dev
```

## Build / lint
```bash
npm run lint
npm run build
```

## Deploy (Vercel)
1. Push to GitHub (`https://github.com/abkgami`).
2. Import repo in Vercel, framework preset Next.js.
3. Set production domain to `abks-portfolio.vercel.app`.
4. Replace `public/Yahaya_Abubakar_Frontend_Engineer_Resume.pdf` with final résumé (keep filename).
